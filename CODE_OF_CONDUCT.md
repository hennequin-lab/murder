# Code of Conduct

This is a small research lab. Be direct and respectful. Critique code and
ideas, not people. Harassment, discrimination, and sustained disruption are not
welcome.

If a disagreement cannot be resolved in review, ask the PI to decide. Report
sensitive incidents privately to the PI rather than in a public issue.

This is adapted from the Contributor Covenant, version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
